# PDCH PHQ/HAMD 结果汇总与审计包

本目录保存当前可追溯的 PDCH PHQ/HAMD 结果表。原始 JSON、原始金标准和 API 密钥没有写入或修改；缺失字段保持缺失，不用金标准回填预测值，也不把 `9` 改成 `0`。

## 先看哪一个文件

1. `PDCH_PHQ_HAMD_multifield_analysis_bilingual_20260806.xlsx`：22 个工作表的多字段深度分析总表。适合先看结论、字段覆盖、基线与条件效应、置信度、证据、理由文本、维度规律、被试难度、模型分歧和输出可靠性。表头采用“中文 (english)”格式，每个 sheet 都写明目的、数据范围、方法、公式、意义和限制，并保留 8 张公式卡片图片。
2. `PDCH_PHQ_HAMD_all_results_all_fields_20260802.xlsx`：完整字段底表。`03_全部主结果` 一行对应一个被试×模型×思考模式×条件，保留总分、等级、逐维度分数、置信度、概率、证据、理由、源文件和哈希；`04_探索性索引` 保留 C17–C24 的被试级索引；`05_未映射字段` 和 `07_字段字典` 用于字段追溯。

## 本次核验与修正

- PHQ 维度级证据覆盖率重新核验为 `23,455 / 36,288 = 64.64%`。计算分母为 `189 人 × 3 模型 × 8 个评分条件 × 8 个 PHQ 条目`。
- 文本占位符 `null`、`none`、`nan`、`n/a`、`[]`、`{}` 按缺失处理；因此不会把字符串占位符误算成证据。
- PHQ 阳性维度证据覆盖率为 `99.90%`，零分维度证据覆盖率为 `46.33%`；零分无证据可能是结构性“未发现症状”，不能直接判定为运行失败。
- 理由字段在重新解析前缺失 14 条，从其他合法变体恢复 12 条，仍有 2 条确实缺失。
- 发现 6 条 `score_final` 候选记录，仅作为审计标记；不覆盖现有分数。
- 原始 JSON 未修改；没有把金标准写入预测；没有把预测 9 转成 0。
- 8 张公式卡片图片、22 个 sheet、双语表头已核验；无合并单元格、无公式错误标记。

## 解释边界

- C01/C03 等基线标记保留在表中；条件比较只应在同一批被试上做配对比较。
- C17–C24 是独立事件/探索性条件，不作为主结果性能结论。
- HAMD 的预测 `9` 表示无法评估/拒答，不能当作 0 分；PHQ 合法条目分值也不能用超范围值替代。
- 当前包是字段完整的结果数据库和描述性/探索性分析包；它不自动产生因果结论、临床部署结论或外部验证结论。
- 原始运行目录和大体积 NDJSON 未上传，原因是保护原始数据与控制仓库体积；每个审计 JSON 保存了输入哈希，可用于回到本地源文件复核。

## 伴随审计文件

`multifield_audit.json` 保存输入哈希、解析数量、重复记录和缺失修复记录；`multifield_workbook_audit.json` 保存工作簿结构核验；CSV 文件提供字段覆盖、证据汇总、维度汇总、条件稳定性、基线效应、核心结论及异常候选的可导入版本。
