# A 主方案 + B 补充方案完整总表

这个包把 PHQ/HAMD 的量表内方案选择、A 主方案、B 补充、NAE、抵消、外推性和稳定性放在一个工作簿中。

## 最终判断

- PHQ 和 HAMD 必须分开看整体总分 MAE，不能合并成一个效应量。
- 两个量表的主方案都为 A：PHQ 平均 ΔMAE=-0.602；HAMD 平均 ΔMAE=-0.409。
- B 的条目层证据更均衡，但总分效应较小，因此作为补充敏感性分析。
- PHQ/DeepSeek、PHQ/Qwen 的 A 和 B 都有当前队列内总分 MAE 外推支持；HAMD 三个 AI 的 A/B 都未达到稳定外推。
- A/B 的总分改善均不能直接解释为逐条评分更准确，因为 NAE 或抵消率没有同步改善。

`A_B方案完整分析总表.xlsx` 是汇报用总表；`00_scale_specific_selection.csv` 是 PHQ/HAMD 分开选择的结构化表；`03_A_B_comparison.csv` 是六个模型×量表单元的 A/B 外推对照。
